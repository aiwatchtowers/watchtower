You read the dialog with markdown rendered, and you can write to the agent, stop it, answer its permission prompt and open its asks without switching to the terminal. Four states of one pane are shown below; the numbers match the notes.

1 · The agent is working

The everyday view. It opens at the newest message and follows the bottom while the agent writes.

  1. 1Your lines on the right, in a bubble. Lines that came from the phone, an ask answer or a review round carry "via Watchtower" in the caption, as today.
  2. 2Agent text with full markdown: headings, lists, bold, code blocks, links. It is the same renderer as AI Chat, so it is no longer raw ##.
  3. 3Service messages from Claude Code (a background task finished, a message from another session) become one grey event line instead of your bubble. Click it to expand the full text.
  4. 4A subagent is a card with its live status. Click opens it in this same pane (state 3).
  5. 5A line written while the agent works is queued (dashed bubble) and is typed into the session when the agent stops. You can cancel it until then.
  6. 6The composer. Return sends (Shift-Return adds a new line). While the agent works, the round button is Stop, the same as Esc in the terminal. A line starting with / is sent as a slash command.

  2. 2A line you send now is queued and goes in after the prompt is answered, so it never lands inside the prompt.

3 · Inside a subagent

The subagent replaces the feed in the same pane. There is no modal window and no Done button.

  1. 1A path bar: ‹ Back (also Esc and ⌘[) and the path. Each part of the path opens that level.
  2. 2The task the subagent got, then its text and its report, with full markdown.
  3. 3A nested subagent opens one level deeper, and the path grows.
  4. 4No composer here. A line typed into a subagent screen would reach the main agent, the same rule as on the phone.

4 · Long history, asks and the end of a session

A long session opens at once on its newest messages; older ones load as you scroll up.

  1. 1Lazy loading. The pane shows the newest messages first and keeps finished rows from re-rendering. Scrolling to the top loads the next older batch while the scroll position stays where it was.
  2. 2An open ask of this session shows as a card. Open Ask opens it where asks are answered today. The answer is delivered into the session as before.
  3. 3A finished or stopped session has no composer. The pane keeps the whole history readable.
