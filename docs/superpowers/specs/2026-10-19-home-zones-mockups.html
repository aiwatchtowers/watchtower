What to look at
  • Above the orange NOW line: what waits for you, at most 7 rows, newest within each kind. 2 more expands the list in place. A row you already read in Catch-Up is dimmed (the email).
  • Hover a row: Open · ✓ Done · Hide. A proposal only opens, because it needs its review in Inbox.
  • Below NOW: the rest of today by time, the next meeting in bold. Then Tomorrow, meetings only.
  • On the right: Workbench (only live sessions and open asks), links with a short status, and today's numbers in muted text.
  • Learn Watchtower at the end of the right column (the columns can differ in height; the page scrolls as a whole): 3 features at a time, picked from about 190 cards written in the user guide, with cards new in this version first. Got it, or trying a feature, marks it seen in the database and the next one takes its place. See all opens the full list. Built in #718.
  • Every zone uses the same card and the same header style.

The cards live in the user guide as small hidden blocks under the heading they teach (id, title, one line, area, level, kind, since, action). A release stamps since on new cards, so after an update they come first with a NEW badge. A card can replace an older one: if you had seen the old card, the new one shows as UPDATED with what changed; if you had not, you only get the current card. "Seen" is stored in the database: Got it, the button pressed, or the feature already in use.
