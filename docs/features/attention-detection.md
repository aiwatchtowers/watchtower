# Attention detection — the inbox feeder (2026-09-14, replaces the Assistant Inbox + Dashboard)

- `internal/inbox/` is a **mechanical** pipeline with zero AI calls: `Pipeline.Run` = dedup → detectors (Slack mentions/DMs/thread replies/reaction requests per enabled account, Jira, Calendar, Gmail, IMAP, `briefing_ready`) → rule-based auto-resolve (INBOX-02: answering in the source resolves the item) → archive/unsnooze → watermark (INBOX-09: a detector error freezes `inbox_last_processed_ts`). Daemon phase `phaseInbox`, gated `inbox.enabled` (feature `secretary-inbox`, "Attention detection", `CostNone`).
- Slack grouping (`createItemsFromCandidates`, board #586): candidates are deduped by (channel, ts) — first detector wins, mentions come first — then grouped by `(channel, thread_ts)`. A **thread** group is one conversation — its item carries the thread's latest message and a fold into the pending thread item overwrites its text (`UpdateInboxItemSnippet`). A **channel** group (`thread_ts = ''`: plain channel messages, DMs, reaction requests) is many unrelated messages — migration 00130 adds `inbox_items.mentions` (JSON `[{ts,sender,trigger,text,permalink}]`, oldest first, the 20 newest, `db.PackInboxMentions`; text truncated to 300 runes), `mentions_earlier` (count that fell off) and `mentioned_at`. A fold into the pending channel item of any age goes through `AppendInboxMentions`: seeds a pre-00130 or malformed (logged) row from its own message, dedupes by ts, ignores a message older than the oldest kept once some fell off, and writes — `mentioned_at`, unread, top-level text to the newest — only when the list grows. The detectors' dedupe also skips a ts listed in any item's `mentions` (`notListedInMentions`, malformed JSON reads as empty). The closing-signal skip is checked per message in a channel group. `FindPendingInboxByThread` returns a read error instead of "none" (INBOX-09). Readers: Catch-Up gathers and acknowledges by `MAX(created_at, mentioned_at)` (Go and Swift, CATCHUP-01), meta `· 3 mentions`/`· 3 messages` (`db.InboxMentionCountLabel`, Swift `InboxItem.mentionCountTitle`), body = one `Name: text` line per message (`InboxMentionLines`); the briefing's inbox block lists them; the Desktop `InboxItemInline` shows the title, "+N earlier", and each message with its sender and an **Open** link (`InboxItem.mentionList`, decoded once in `init(row:)`, malformed logged). The backfill (`backfillAccountMentions`) stays create-only and writes `'[]'`.
- `inbox_items` has **no screen of its own**. Its readers are Catch-Up (`needs_you`), the daily briefing, meeting prep (attendee context), custom tracks (scan material) and the Slack reaction sync. The sidebar "Inbox" tab is the action strip (agent proposals + due reminders) with the Learned (cross-pipeline `inbox_learned_rules`) and Profile (`workspace.secretary_profile`) tabs — see Reaction Commands Wave 2.
