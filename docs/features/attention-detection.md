# Attention detection — the inbox feeder (2026-09-14, replaces the Assistant Inbox + Dashboard)

- `internal/inbox/` is a **mechanical** pipeline with zero AI calls: `Pipeline.Run` = dedup → detectors (Slack mentions/DMs/thread replies/reaction requests per enabled account, Jira, Calendar, Gmail, IMAP, `briefing_ready`) → rule-based auto-resolve (INBOX-02: answering in the source resolves the item) → archive/unsnooze → watermark (INBOX-09: a detector error freezes `inbox_last_processed_ts`). Daemon phase `phaseInbox`, gated `inbox.enabled` (feature `secretary-inbox`, "Attention detection", `CostNone`).
- Slack grouping (`createItemsFromCandidates`, board #586): candidates group by `(channel, thread_ts)`. A **thread** group is one conversation — its item carries the thread's latest message and a fold into the pending thread item overwrites its text (`UpdateInboxItemSnippet`). A **channel** group (`thread_ts = ''`: plain channel messages, DMs) is many unrelated messages — every one lands in `inbox_items.mentions` (migration 00130, JSON `[{ts,sender,text,permalink}]`, oldest first), a fold into the pending channel item of any age appends (`AppendInboxMentions`: seeds a pre-00130 row from its own message, dedupes by ts, top-level text follows the newest, `read_at` cleared), and the closing-signal skip is checked per message. `FindPendingInboxByThread` returns a read error instead of "none" (INBOX-09). Readers: Catch-Up's `ListCatchupInbox` meta ("· N messages, the latest shown") and the Desktop `InboxItemInline` ("N mentions" + an **Open** link per message, `InboxItem.decodedMentions`). The backfill (`backfillAccountMentions`) stays create-only and writes `'[]'`.
- `inbox_items` has **no screen of its own**. Its readers are Catch-Up (`needs_you`), the daily briefing, meeting prep (attendee context), custom tracks (scan material) and the Slack reaction sync. The sidebar "Inbox" tab is the action strip (agent proposals + due reminders) with the Learned (cross-pipeline `inbox_learned_rules`) and Profile (`workspace.secretary_profile`) tabs — see Reaction Commands Wave 2.
- Retired on 2026-09-14 (spec `docs/superpowers/specs/2026-09-14-inbox-demolition-design.md`): stream triage, the implicit learner, the situations composer + situation cards, per-item/situation feedback, the feed publisher, `phaseFastInbox`, the Dashboard/`InboxFeedView` Desktop code (deleted in the demolition's Desktop half, PR 2), `list_situations`/`get_situation` and the `whats-changed` dev-pack skill. `situations`/`situation_signals` are frozen read-only history (migration 00070). `watchtower profile style-sample` (was `inbox style-sample`) still generates `workspace.style_profile` for meeting follow-ups.
