# Keyboard shortcuts

Every key equivalent in the app. Some work only on a given tab or while a window is in front; that is noted per row.

## Everywhere

| Keys | Action |
|---|---|
| ⌘B | Collapse or expand the sidebar menu |
| ⌃⌘R | **Run Automation…** (only while the Automations feature is on) |
| ⌘S | **Save** on Settings tabs that have a Save bar |
| ⌘Q | **Quit Watchtower** |
| ⌃⌥D | Global hotkey: voice dictation / quick capture, from any app |
| ↩ / esc | Default / cancel button in sheets |

## Chat

| Keys | Action |
|---|---|
| ⌘N | New chat |
| ⌘K | Search chats |
| ⌘↩ | **Save & Send** while editing a sent message |

## Targets and ideas

| Keys | Action |
|---|---|
| ⌘N | New target (Targets tab) |
| ⌘↩ | In the **New Target** sheet: just create, without briefing the assistant (↩ briefs the assistant). In the idea sheet: **Create** |

## Workbench

| Keys | Action |
|---|---|
| ⌘K | **Go to…** palette (↑ ↓ move, ↩ open, ⌘↩ open in split, esc close) |
| ⌥⌘S | Show or hide the sessions panel |
| ⌘[ | Back to the workbench list |
| ⌘T | New session |
| ⌘1 … ⌘9 | Switch to that session (numbers shown in the session switcher) |
| ⌥⌘↩ | **Hand to Session** from a code question |
| ⌃⌘A | **Show Waiting for You** (Navigate menu; works even when the terminal has the keyboard) |

### Sessions panel

These keys work only while the panel has the keyboard: after a click on the list's empty space, or after a click on its label, a group header, a ✕ or the Undo toast.

| Keys | Action |
|---|---|
| ↑ / ↓ | Move the cursor over sessions |
| ↩ | Open the session under the cursor |
| esc | Give the keyboard back |
| ⌘⌫ | Delete the session under the cursor (deferred, with an Undo bar) |
| ⌘Z | Undo that delete |
| Tab / ⇧Tab | Move focus on / back out of the panel |

## Workbench code viewer

The **Navigate** menu is enabled only while a workbench window is in front.

| Keys | Action |
|---|---|
| ⇧⌘O | **Open Quickly…** |
| ⇧⌘F | **Find in Workbench…** |
| ⌃⌘J | **Go to Definition** |
| ⇧⌘U | **Show All Usages** |
| ⌘I | **Ask AI** about the selection |
| ⌃6 | **File Symbols…** |
| ⌃⌘← / ⌃⌘→ | **Back** / **Forward** |

## Voices

On the active card of the voice-labelling window.

| Keys | Action |
|---|---|
| Space | Play or stop the first clip |
| 1–9 | Pick that candidate in the list |
| ↩ | **Confirm** |

## Owner asks (no field focused)

Bare keys; they work only while no text field, terminal or editor has the keyboard. See [Asks](../features/workbench/asks.md).

| Keys | Action |
|---|---|
| A | On the workbench page: open **Waiting for you** |
| J / K, ↓ / ↑ | Next / previous ask |
| Tab / ⇧Tab | Next / previous question or step in the drawer |
| 1–9 | Pick that option; on a step, 1 Works, 2 Doesn't work, 3 Didn't check |
| 1–3 | Answer a Quick ask with that option |
| ↩ | Write in the field, or open the ask from a banner or card |
| N / P | In a review: next / previous margin comment |
| ⌘↩ / ⌘⇧↩ | Primary / secondary answer button (the button's tooltip shows its key) |
