# Keyboard shortcuts

Every key equivalent in the app, by area. **Help → Keyboard Shortcuts** shows the same list in a window. On a workbench page the **Workbench** menu holds the workbench's chords and the **Navigate** menu the Files editor's; the tray's **New Voice Idea** shows ⌃⌥D. Some chords differ by tab: ⌘K is **Search chats** in Chats and **Go to…** on the Workbench tab, ⌘N is **New chat** in Chats and **New target** in Targets.

### Chats Panel

After a click on the panel's empty space, a section label or the older header.

| Keys | Action |
|---|---|
| **↑ / ↓** | Move the highlight |
| **Return** | Open the highlighted chat |
| **⌘⌫** | Delete the highlighted chat |
| **⌘Z** | Undo the delete |
| **Esc** | Leave the chat list |

### Waiting for You

Single keys work while no field, terminal or editor has the keyboard.

| Keys | Action |
|---|---|
| **J / K** | Next / previous ask (↓ / ↑ on a card) |
| **Return** | Open the ask in the drawer; in the drawer, write in the outlined field |
| **1–3** | Answer a Quick ask with that button |
| **Tab / ⇧Tab** | Next / previous question or step (drawer) |
| **1–9** | Pick that option, or mark a check step (drawer) |
| **N / P** | Next / previous margin comment (review) |
| **⌘Return** | Answer, Send or Approve |
| **⌘⇧Return** | Request changes (review) |
