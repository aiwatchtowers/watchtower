# Watchtower security audit

Resolve the repository root with `git rev-parse --show-toplevel` and read
`docs/security/review-workflow.md` from that checkout. Follow its scope, review
and reporting instructions. Continue in the current Codex session and use
the review inputs supplied with the request.
